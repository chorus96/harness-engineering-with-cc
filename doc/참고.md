# 《하네스 엔지니어링 with 클로드 코드》 — 참고 자료

> 책 **《하네스 엔지니어링 with 클로드 코드》**(황민호(로빈 황) 저, 한빛미디어, 도서코드 B2817272480) 관련 참고 자료를 웹 검색(2026-08 기준)으로 조사해 유형별로 정리했습니다.
> 각 요약은 원문 복제가 아니라 제목·검색 스니펫·(접근 가능한 경우) 본문을 근거로 재작성한 것입니다. 일부 링크는 현재 실행 환경의 네트워크 정책에서 직접 열람이 차단되어 스니펫만으로 요약했습니다 — 정확한 내용은 각 원문을 확인하세요.

---

## 1. 책 개요와 저자

- **책**: AI 에이전트를 도구로 쓰는 단계를 넘어, **스스로 일하는 에이전트 팀을 직접 설계·운영**하는 방법(하네스 엔지니어링)을 체계적으로 정리한 실전서. 단일 에이전트의 한계 → 하네스 3기둥(에이전트·스킬·오케스트레이터) → 메타스킬 → 6가지 아키텍처 패턴 → 실전 4팀(코드 리뷰·풀스택·레거시 마이그레이션·디버깅/RCA) 순으로 전개.
- **저자**: **황민호(로빈 황, GitHub `revfactory`)** — 카카오의 AI 네이티브/전략 관련 리더. 공개한 하네스 오픈소스가 GitHub에서 수천 스타를 받으며 커뮤니티의 주목을 받음.
- **핵심 명제**: "모델이 아니라 하네스가 결과를 결정한다." 저자의 A/B 실험에서 같은 Claude 모델이 `.claude/` 구성 차이만으로 품질 점수가 크게 상승했다고 소개됨(검색 스니펫 기준 49.5 → 79.3).

> 참고: 본 저장소의 예제·문서([`예제코드.md`](./예제코드.md), [`목차.md`](./목차.md))가 이 책의 실습 예제를 다룹니다.
